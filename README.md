# なに税？（zeikin-nanizei）

ふだんの場面（給料・買い物・温泉・車検・出国など）を見て、その場面でかかる税を当てる1日5問の学習ゲーム。正解したら「どこに納める？」（国・都道府県・市町村）も選ぶ。

遊ぶ: <https://satou-aaaaa.github.io/zeikin-nanizei/>

- 中身は財務省「税の種類に関する資料」の税目の表（<https://www.mof.go.jp/tax_policy/summary/condition/a01.htm>）と、e-Gov 法令検索の各税法の条文で確かめたことだけです。税率や税額の計算は扱いません。
- このゲームは税金の助言や、公式の情報の代わりではありません。正しい税の決まりは国税庁・お住まいの自治体・e-Gov 法令検索で確かめてください。
- 場面と人・会社はすべて練習のために作ったものです。記録は遊ぶ人のブラウザだけに残り、外へ送りません。
